## Descripción

RedTerrestre es un sitio web empresarial desarrollado para una empresa dedicada al transporte terrestre de carga y servicios logísticos.

El proyecto tiene como propósito presentar la empresa, comunicar sus servicios y ofrecer diferentes medios para que los clientes puedan solicitar información y cotizaciones.

La interfaz está diseñada para facilitar la navegación, adaptarse a diferentes dispositivos y ofrecer contenido en español e inglés.

## Características principales

### Información empresarial

- Presentación de la empresa.
- Sección de información institucional.
- Descripción de los servicios disponibles.
- Información de contacto.

### Servicios de transporte

El sitio presenta soluciones relacionadas con:

- Transporte de carga general.
- Transporte de carga sobredimensionada.
- Transporte de carga IMO.
- Soluciones con plataformas y chasises.
- Servicios de almacenamiento.

### Cotizaciones y contacto

- Acceso directo a WhatsApp.
- Formulario de cotización detallada.
- Envío de información de cotización mediante WhatsApp.
- Información de contacto empresarial.

### Experiencia de usuario

- Diseño adaptable a diferentes tamaños de pantalla.
- Navegación entre secciones.
- Selector de idioma español e inglés.
- Elementos visuales y animaciones.
- Componentes interactivos.

## Instalación y ejecución

RedTerrestre es un proyecto frontend estático. No requiere instalar un backend ni configurar una base de datos para visualizar el sitio.

### 1. Clonar el repositorio

```bash
git clone https://github.com/SaredGarcia/RedTerrestre.git
```

### 2. Entrar en el proyecto

```bash
cd RedTerrestre
```

### 3. Ejecutar localmente

Puedes abrir `index.html` directamente en tu navegador o utilizar Visual Studio Code con la extensión Live Server.

### 4. Navegar por el sitio

La página principal permite acceder a las diferentes secciones:

- Inicio: `index.html`
- Nosotros: `about.html`
- Servicios: `service.html`
- Contacto: `contact.html`

## Consideraciones técnicas

- El proyecto está desarrollado como sitio web frontend.
- No utiliza una base de datos propia.
- Las solicitudes de cotización se preparan para enviarse mediante WhatsApp.
- Los recursos externos y bibliotecas deben estar disponibles para conservar todas las funcionalidades.
- La configuración del dominio depende de los registros DNS y de GitHub Pages.
